# Explicacion de codigo
En los retos de DataLab se utilizaron diferentes estructuras de programación en Python, principalmente los ciclos `for`, `while` y las condiciones `if`. Estas herramientas permiten repetir instrucciones, tomar decisiones y procesar diferentes datos de manera automática.

En el **Reto 2, El Procesador de Lotes**, se utilizó un ciclo `for` para simular la lectura de 10 sensores de temperatura. Se empleó `range(1, 11)` para generar los números del 1 al 10. En cada repetición, el programa utiliza `print()` para mostrar el número del sensor y el mensaje `"Temperatura procesada"`. Cuando el ciclo termina después de procesar los 10 sensores, se muestra el mensaje `"Lote completo"`. Este código demuestra cómo utilizar un ciclo `for` cuando conocemos previamente la cantidad de veces que necesitamos repetir una acción.

En el **Reto 3, Validador de Contraseña**, se utilizó un ciclo `while True` para simular un ciclo `do-while`, ya que Python no cuenta con una estructura `do-while` directamente. El programa solicita al usuario una contraseña mediante `input()`. Después, mediante una condición `if`, comprueba si la contraseña ingresada es igual a `"Data2026"`. Si es correcta, muestra `"Acceso concedido"` y utiliza `break` para terminar el ciclo. Si la contraseña es incorrecta, utiliza `else` para mostrar `"Acceso denegado, intente de nuevo"` y vuelve a solicitar la contraseña. De esta manera, el programa continúa funcionando hasta que el usuario introduce la contraseña correcta.

En el **Reto 4, El Filtro de Datos**, se combinaron un ciclo `for` y una condición `if`. Primero se creó una lista con diferentes valores: `[10, 55, 2, 80, 15, 100, 40]`. Luego, el ciclo `for` recorre cada uno de los elementos de la lista y los almacena temporalmente en la variable `valor`. La condición `if valor > 50` comprueba si el número es mayor que 50. Si cumple la condición, el programa muestra el valor mediante `print()`. Si no la cumple, se ejecuta `else` y aparece el mensaje `"Valor descartado"`. Esto permite filtrar información y mostrar únicamente los datos que cumplen una determinada condición.

En conclusión, estos tres retos permiten comprender algunas de las estructuras fundamentales de Python. El ciclo `for` sirve principalmente para repetir una acción sobre una cantidad determinada de elementos, mientras que `while` permite repetir instrucciones mientras se mantenga una condición. Por otro lado, `if` y `else` permiten que el programa tome decisiones dependiendo de los datos que recibe. Finalmente, `break` permite detener un ciclo cuando se cumple una condición específica. La combinación de estas herramientas permite crear programas más dinámicos y capaces de procesar información automáticamente.
